# 🛡️ API Shield — Rate Limiting & API Analytics System

## 🚀 Overview

API Shield is a full-stack project built using **Spring Boot (Java)** and **React.js** that provides API security through API Key authentication, rate limiting, and real-time analytics dashboard.

It simulates a lightweight API Gateway system that tracks usage, blocks excessive requests, and visualizes traffic data.

---

## ✨ Features

- 🔑 API Key Authentication
- 🚦 Fixed Window Rate Limiting
- ❌ Request Blocking on limit exceed
- 📊 Real-time analytics dashboard
- 📈 Total / Allowed / Blocked request tracking
- 🏆 Per-API Key usage statistics
- 📜 Request logging system
- 📉 Data visualization using charts
